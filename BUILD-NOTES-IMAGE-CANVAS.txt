Alpha AI build update — Image Studio + Canvas AI

Image Studio:
- Server-only POST /api/images route using OPENAI_API_KEY and OPENAI_IMAGE_MODEL (default gpt-image-1).
- Prompt guidance, visual styles, square/landscape/portrait formats, preview, and unique PNG download filename.
- Generated PNG can be attached as an actual image asset to Alpha Canvas.
- Best-effort per-instance limit of four image requests per ten minutes. This is not a shared production quota.

Alpha Canvas:
- Edit, preview, split view, manual save, and debounced autosave.
- Draft and generated image assets persist in browser IndexedDB on this device; localStorage is a text-only fallback.
- Generated images can be previewed, removed, and downloaded individually.
- Export Markdown, TXT, or standalone HTML with embedded PNG image data.
- Ask Alpha to improve, proofread, simplify, expand, summarize, outline, or provide tutor feedback.
- Selected editor text is sent for a focused edit; otherwise the whole draft is used. Suggestions are shown separately and are not applied until the user chooses.
- Server-only POST /api/canvas uses OPENAI_API_KEY and OPENAI_MODEL, with input size validation and a best-effort per-instance rate limit.

Security and limitations:
- Never put OPENAI_API_KEY in frontend/VITE variables.
- Both rate limiters are per server instance and are only prototype protection. Production needs authentication, shared quotas, and abuse monitoring.
- AI calls incur OpenAI API charges. Canvas content is sent to the configured AI service only when the user presses Ask Alpha.
- Canvas drafts/images remain local to the browser and are not synced to an account or cloud database.
